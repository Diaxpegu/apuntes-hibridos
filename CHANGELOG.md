# Registro de cambios

## [0.1.1] - 2026-10-29

- Corregido el alcance: aplicación web para computadores y **aplicaciones instalables** para tablets Android e iPadOS, con igual prioridad funcional.
- Eliminadas comparaciones comerciales con aplicaciones de terceros en descripciones de producto y objetivos.
- Incorporados RF-041 a RF-044 sin alterar los identificadores RF-001 a RF-040.
- Actualizados los requisitos no funcionales de compatibilidad, fidelidad, persistencia local y uso fuera de línea.
- Separada la validación de apps móviles (H2-A) de la sincronización multiplataforma (H2).
- Revisada la arquitectura propuesta: web, apps instaladas, formato común y persistencia local por plataforma.
- Ampliadas y corregidas las pruebas de web, lápiz Android/Apple, sincronización y aceptación, sin identificadores duplicados.
- Actualizados riesgos, decisiones, acuerdos, documentación para cliente.

> Revisión documental: no hay software implementado ni pruebas ejecutadas todavía. Las tecnologías son candidatas y el cliente aún debe aprobar el alcance.
