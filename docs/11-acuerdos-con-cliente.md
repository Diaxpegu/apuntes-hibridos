## Confirmaciones de alcance

- Que los trazos permanezcan fijos es una **decisión de producto**, no un defecto a resolver automáticamente.
- Página A4 fija y separación de capas son recomendaciones aceptadas provisionalmente para prototipar, sujetas a experiencia real.
- El producto tendrá aplicación web para computadores y aplicaciones **instalables** para tablets Android e iPadOS.
- Android e iPadOS tendrán las mismas funciones esenciales; el orden de validación puede variar por disponibilidad de dispositivos.
- Abrir la web en el navegador de una tablet no satisface el requisito de aplicación instalable ni demuestra sincronización.
- Las tres plataformas compartirán un formato de documento, incluidos los datos de texto, páginas, trazos y tarjetas.
- Se validará el motor de edición multiplataforma con prototipos antes de declararlo definitivo.

## Para acordar más adelante con el cliente

1. Dueño de los derechos, responsabilidades del cliente y condiciones de entrega.
2. Nombre/marca y permisos para usar plantillas o imágenes de terceros.
3. Límites exactos de versiones gratis/premium/permanente.
4. Qué formato de importación/exportación es indispensable para lanzamiento.
5. Presupuesto, disponibilidad y criterios para aceptar hitos comerciales.

## Gestión de cambios

Si el cliente cambia un requisito, registrar fecha, motivo, impacto y aprobación; no borrar el historial de la decisión anterior. Usar el registro de decisiones y tareas del repositorio.
